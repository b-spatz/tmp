Start collecting summary of the various data produced and used by Avare[X]:
tabular data (airports, METARs) and charts/plates/CSUP

Overview:
Charts, plates/CSUP shared between Avare[X] (formats, server download locations, client folders uses)
Both databases[x].zip provide main.db, but incompatible (same tables have differing schemas, different/new tables)
weather.db differs with Internet sources; GDL90 will trickle in to update via caching layer?
   Avare: downloaded from apps4av.org server periodically by client, updated on server every 10 minutes
   AvareX: downloaded directly from Internet sources by client on demand

AvareX Assets
Come from www.apps4av.org/regions/[cycle], avare.buggle.org/[cycle]/
Cycle data (e.g. "2513", current via version.php from root URL above):
charts: <region>_{SEC,TAC,ENR_L{LHA},HEL,FLY}.zip: basemap tiles .webp per WMS z/x/y format
   tiles/ folder on client under <type>/<z>/<x>/<y>.webp for type SEC=0, ENR_L=3, etc.
plates/CSUP: <region>_{TPP,CSUP}.zip: .png
   {plates,afd}/ folder on client under <airport_identifier>/*.png (was in "Airport/Facility Directory" before "Chart Supplement")
SQLite databases:
   main.db: download from <cycle>/databasesx.zip, incompatible with Avare (by differing schemas and tables)
   weather.db: created on client from various Internet sources; updated from Internet or GDL90
   user.db: created on client initially, collects state and settings from user interaction/config; can import
